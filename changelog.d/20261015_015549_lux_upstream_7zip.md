### Security

- \[Lux\] The server image extracts archives with upstream 7-Zip 26.04 instead of
  Ubuntu's 7zip 23.01 package, which has NTFS handler flaws (CVE-2023-52168,
  CVE-2023-52169) fixed only upstream and in Ubuntu Pro
- \[Lux\] The YOLOv7 sidecar no longer carries python3.12-venv or the pip and
  setuptools wheels it bundles once its virtual environment is built
